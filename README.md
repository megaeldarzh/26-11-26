# Обработка исключений на Python

Учебный проект с 12 консольными заданиями и графическим приложением на Tkinter.

## Запуск графического приложения

Требуется Python 3.10 или новее с установленным Tkinter.

```powershell
python app.py
```

В приложении выберите задание в боковом меню, заполните поля и нажмите
«Выполнить». Состояние библиотеки хранится в `library.json`, журнал ошибок —
в `errors.log`.

## Запуск консольных заданий

```powershell
python 01_bank_account.py
python 02_list_average.py
python 03_file_sum.py
```

Файл `numbers.txt` содержит пример чисел для задания 03. Остальные задания
запускаются аналогично: замените номер и имя файла на нужные.

## Задания

1. Банковский счёт
2. Среднее списка
3. Сумма чисел из файла
4. Авторизация с блокировкой после трёх ошибок
5. Калькулятор
6. Учёт товаров и продаж
7. Регистрация с проверкой полей
8. Обновление элемента матрицы
9. Заказы с проверкой остатков и лимита
10. Собственные исключения
11. Запись ошибок в журнал
12. Библиотечная система с сохранением данных
